# Template de MCP

- **Destino de instalação:** `projeto` (`.mcp.json` na raiz do projeto, servidores que o time compartilha) ou `usuario` (`~/.claude.json`, servidores só seus). Escolha **um** valor ao instanciar.
- O JSON está em [`mcp.json`](mcp.json). Ele não traz chaves extraoficiais. Não apresente um servidor de terceiros como configuração oficial da Anthropic.

Fonte: NNN — URL — acesso AAAA-MM-DD (America/Sao_Paulo)
