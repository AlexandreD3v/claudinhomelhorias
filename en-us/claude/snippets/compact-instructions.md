## Compact instructions

- When compacting, keep: the current task, decisions already made, the paths of the files we are working on, and what is still left to do.
- Drop: long command output, contents of files already applied, and abandoned attempts (if you need to undo the last turns, use `/rewind`, not `/compact`).
