# Sources

US English mirror of [`fontes/`](../../fontes/) (pt-BR, canonical). One note per site, named `NNN-slug.md` (here with an English slug and the same number). Always start from [`templates/source.md`](../templates/source.md) and update [`INDEX.md`](INDEX.md) in the same cycle, in both languages.

Each note declares a **theme** (`Tema`), repeated in the index `Tema` column:

- `claude-code` — what applies to Claude Code; the artifacts go to [`claude/`](../claude/).
- `claude-app` — what applies to the Claude app (chat, Desktop, claude.ai); the artifacts go to [`claude-app/`](../claude-app/).
- `ambos` (both) — serves both; one artifact in each folder, with a cross-reference.

Only what serves neither is discarded (`descartado`). The table of processed sources is in [`INDEX.md`](INDEX.md).
