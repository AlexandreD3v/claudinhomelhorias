# Fontes

Uma nota por site, no padrão `NNN-slug.md`. Comece sempre por [`templates/fonte.md`](../templates/fonte.md) e atualize [`INDICE.md`](INDICE.md) no mesmo ciclo.

Cada nota declara um **tema**, repetido na coluna `Tema` do índice:

- `claude-code` — o que se aplica ao Claude Code; os artefatos vão para [`claude/`](../claude/).
- `claude-app` — o que se aplica ao app Claude (chat, Desktop, claude.ai); os artefatos vão para [`claude-app/`](../claude-app/).
- `ambos` — serve aos dois; um artefato em cada pasta, com referência cruzada.

Só se descarta (`descartado`) o que não serve a nenhum dos dois. A tabela de processadas está em [`INDICE.md`](INDICE.md).
